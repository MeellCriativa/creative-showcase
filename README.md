# Creative Showcase

Crie um programa chamado Vitrine Criativa, pensado principalmente para uso pelo celular, com interface moderna, simples, profissional e intuitiva.



IMPORTANTE: quero um programa de criação e gerenciamento de catálogos digitais, e não apenas um site institucional.



OBJETIVO



O programa permitirá que cada usuária crie seu próprio catálogo de produtos, personalize sua vitrine e compartilhe o catálogo com seus clientes através de um link.



O cliente não precisa criar conta para comprar.



PAINEL DA VENDEDORA



Após fazer login, a usuária deverá conseguir:



- Criar seu catálogo.

- Adicionar nome da loja.

- Adicionar logotipo.

- Adicionar foto de perfil ou capa.

- Informar número do WhatsApp para receber pedidos.

- Escolher cores do catálogo.

- Criar categorias.

- Adicionar, editar e excluir produtos.

- Adicionar várias fotos aos produtos.

- Colocar nome do produto.

- Descrição.

- Preço.

- Preço promocional.

- Variações, como tamanho, cor, modelo ou sabor.

- Informar se o produto está disponível ou esgotado.

- Organizar a ordem dos produtos.

- Visualizar o catálogo antes de compartilhar.



CATÁLOGO DO CLIENTE



Quando alguém abrir o catálogo compartilhado, deverá visualizar uma interface própria para celular, semelhante a um aplicativo de compras.



Mostrar:



Nome da loja



Categorias:



"Todos | Novidades | Mais vendidos | Promoções"



Depois mostrar os produtos em cards com:



- Foto

- Nome

- Preço

- Preço promocional

- Botão "+ Adicionar"



Ao tocar em um produto, abrir seus detalhes.



CARRINHO



O cliente poderá:



- Escolher produtos.

- Escolher variações.

- Selecionar quantidade.

- Adicionar vários produtos.

- Aumentar ou diminuir quantidades.

- Excluir produtos.

- Visualizar subtotal.

- Visualizar o total do pedido.



Não quero pagamento obrigatório dentro do programa neste primeiro momento.



FINALIZAÇÃO PELO WHATSAPP



O principal diferencial será a finalização pelo WhatsApp.



Quando o cliente tocar em:



Finalizar pedido pelo WhatsApp



o programa deverá gerar automaticamente uma mensagem organizada, por exemplo:



Olá! Quero fazer este pedido:



Produto: Agenda Floral

Quantidade: 2

Valor: R$ 35,00



Produto: Planner 2027

Quantidade: 1

Valor: R$ 42,00



Total: R$ 112,00



E abrir automaticamente uma conversa no WhatsApp da vendedora com essa mensagem preenchida.



O cliente só precisará tocar em enviar.



COMPARTILHAMENTO



Cada catálogo deverá possuir seu próprio link compartilhável.



A vendedora poderá copiar esse link e enviar pelo:



- WhatsApp

- Instagram

- Facebook

- Telegram

- Bio das redes sociais



IMPORTANTE



O sistema precisa ser mobile-first.



Quero que a experiência principal seja pensada para celular, parecendo um programa/aplicativo e não um site comum.



A interface da vendedora também deve funcionar perfeitamente pelo celular.



Crie primeiro a estrutura funcional do programa, incluindo:



Login → Painel → Criar catálogo → Categorias → Produtos → Personalização → Visualização do catálogo → Carrinho → Finalizar pedido pelo WhatsApp.



Não implemente funções desnecessárias neste primeiro momento.



Quero começar pelo núcleo funcional do Vitrine Criativa e depois iremos adicionando novos recursos.
